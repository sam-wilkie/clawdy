# Panel and Windows icons

- Claude and Codex: derived from Clawdy's existing pixel-art SVGs.
- Kiro: the `kiro-icon.png` shipped with the locally installed Kiro IDE, used to identify that integration.
- OpenCode: the favicon published at https://opencode.ai/favicon.ico, used to identify that integration.

PNG and ICO variants are generated by `desktop/tools/build-agent-icons.js`. Product names and logos belong to their respective owners; these assets indicate compatibility.
