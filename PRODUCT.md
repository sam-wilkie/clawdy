# Product

## Register

product

## Users

Developers who run local AI coding agents and want to notice their activity without leaving the editor or terminal.

## Product Purpose

Clawdy reflects local coding-agent activity through an animated desktop pet, simulator, or small hardware display. The desktop app should make current sessions and available usage data easy to scan while keeping the user's coding workflow in view.

## Brand Personality

Playful, pixel-art, approachable. The mascot can be expressive while information panels stay clear and calm.

## Anti-references

Avoid overloaded panels, decorative charts, and generic SaaS dashboard styling. Do not expose conversation content when session status and project context are enough.

## Design Principles

- Show live agent state with minimal delay.
- Keep the pet lightweight and unobtrusive until the user asks for details.
- Use local session data only for the desktop activity view.
- Make agent, project, and usage status easy to distinguish at a glance.
- Preserve the pixel-art identity without making controls hard to read.

## Accessibility & Inclusion

Keep text readable, show status with both labels and color, support keyboard access in the activity panel, and respect reduced-motion preferences.
